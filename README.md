# 🍽️ Kitchenly

**Kitchenly** is a smart meal planning and kitchen management app built with Flutter. It helps users plan meals, manage ingredients, track pantry inventory, and generate shopping lists — all in one intuitive, multilingual experience.

---

## 📱 Features

- 🗓️ **Meal Planning**: Create multi-day meal plans with recipes and assign them to specific dates.
- 📦 **Inventory Management**: Track what's in your kitchen and get notified when items run low.
- 🛒 **Shopping List Generator**: Automatically generate grocery lists based on planned recipes.
- 📸 **Recipe Scanner**: Add new recipes by scanning ingredients and steps using OCR + NLP.
- 🌍 **Multi-language Support**: Localized UI (e.g., English, Arabic).
- ☁️ **Cloud Sync**: Data is securely stored and synced with Firebase Firestore.
- 📷 **Image Uploading**: Save and view recipes with images (base64 or URLs supported).
